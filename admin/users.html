Users

Who can sign in to this panel.

Two steps to add someone

The website has no public accounts — the only users are the people who administer it. Creating a login and granting it access are separate:

  1. Create the account in Firebase console → Authentication → Add user, with an email and password. Copy the User UID it generates.
  2. Paste that UID into the form below to grant admin access.

Step one needs the console because creating an Auth account requires server credentials, which a browser page cannot hold safely. Anything that could do it from here could also be abused by anyone who opened this page.
